# Homi — app Android

Descarga la última versión de la app de inmuebles **Homi** en
**[Releases → Latest](../../releases/latest)** (archivo `.apk`).

## Cómo instalar
1. Abre el enlace del `.apk` en **Chrome** desde tu teléfono Android.
2. Toca el archivo descargado → **Instalar**.
3. Si aparece «No se permite instalar apps de esta fuente»: **Ajustes → Permitir de esta fuente**.
4. Si aparece Play Protect: **Más detalles → Instalar de todos modos**.

Este repositorio solo contiene las versiones instalables; el código de la app es privado.
